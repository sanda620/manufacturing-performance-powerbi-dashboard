# Manufacturing Performance & OEE Analytics Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyse manufacturing performance using a synthetic manufacturing dataset. The dashboard provides insights into production output, Overall Equipment Effectiveness (OEE), quality, defects, machine performance, and downtime.

## Objectives
- Monitor manufacturing production performance.
- Evaluate Overall Equipment Effectiveness (OEE).
- Analyse production output against targets.
- Identify quality issues and defect patterns.
- Evaluate machine efficiency and downtime.

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Data Modelling
- Data Visualisation

## Key Performance Indicators
- Overall Equipment Effectiveness (OEE)
- Availability
- Performance
- Quality
- Defect Rate
- Target Achievement
- Total Production Output
- Total Downtime

## Dashboard Features
- Interactive KPI cards.
- Monthly production vs. target analysis.
- Monthly OEE trend analysis.
- Production output by production line.
- Defect category analysis.
- Downtime analysis by reason.
- OEE performance by machine.
- Interactive filters for date, plant, production line, and shift.

## Dataset Disclaimer
This project uses a synthetic sample dataset created for portfolio demonstration purposes. It does not contain actual company operational data and is not affiliated with or representative of MAS Holdings or any other manufacturing organisation.

## How to View
- Open the PDF in the `dashboard` folder for a quick overview.
- Open the `.pbix` file using Microsoft Power BI Desktop to explore the interactive report.
